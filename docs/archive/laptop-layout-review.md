# Adventure layout — #305

This review pass builds on the developer's fantasy-style WIP (`99e0d33`). It preserves the header and Activity Log presentation and implements the developer's first status-rail concept without changing gameplay or save data.

Activity occupies the right column and grows from 18rem at 1024px to 20rem at 1280px, 22rem at 1536px, and 26rem at 1800px (with the default 16px root font). The command rail is centered with an 83rem maximum width (1328px at the default root font). Above 1024px it holds the supplied Adventurer portrait, difficulty/turn badges, HP/MP with inline values and bars, compact gold, visible level/XP progress, and the objective. The supplied flame appears in both the objective and the header. The objective moves onto its own row below 1024px so it cannot squeeze the status fields. Below 1024px, the page scrolls naturally and Activity stacks after the map and hotbars. Character identity spans the mobile status grid, followed by paired health/mana and gold/level fields. The cap is a single layout constraint, so a wider or full-width rail can be compared later without restructuring the sections.

The dock retains four potion slots and six spell slots with their existing shortcuts. It wraps within the page instead of centering an overflowing fixed-width strip; narrow screens show the six spells in two balanced rows. Gold and level retain descriptive accessible text, and the floor label retains heading semantics.

Tile size, map following, scrolling, and keyboard ownership remain unchanged.
