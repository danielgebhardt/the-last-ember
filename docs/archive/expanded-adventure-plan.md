# Expanded adventure story order

Recommended balance configuration: **60×60×20**, character cap **20**. Other valid sizes remain supported for correctness. Work on `codex/expanded-adventure`, one tested commit per story. Completed implementation moves to In review; developer acceptance is separate.

Execution order: Settings focus → opening → progression (#195) → spellbooks/spells → equipment → creatures → discoveries → balance and verification. Progression is established before content tuning; final pacing measurements occur after deeper content exists.
